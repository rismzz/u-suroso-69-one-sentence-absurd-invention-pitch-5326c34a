A deterministic program that writes one sentence to `/output/entry.txt` pitching a ridiculous invention that fixes a tiny everyday annoyance — the SockSync dryer, which pairs your socks over Bluetooth and files a missing-person report the moment one vanishes. No network, no randomness, no model call: the same 117 characters on every run.

## Run it

```sh
python3 main.py
```
